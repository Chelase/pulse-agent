# 参考资料目录（docs/）

本目录存放参考资料、外部规范、技术学习笔记等辅助文档，供 Agent 在执行任务时查阅。

## 判据

写外部参考资料、技术规范摘要、学习笔记、工具使用指南等辅助性文档，放本目录。
若是"必须/不要"的执行约束，放 `../rules/`；若是"系统现在如何工作"，放 `../mechanisms/`。

## 约定

- 文件名用语义化短横线命名。
- 每份参考资料注明来源（URL、书籍、文档版本等）和采集日期。
- 参考资料是辅助性文档，不作为规则或机制的权威来源。
